# Research Basis

The prompt pack follows these current guidance themes from Anthropic and established VTT products:

- persistent project instructions belong in `CLAUDE.md`;
- specialised subagents help isolate focused work and context;
- long-running application work should be decomposed into tractable increments with structured handoff artefacts;
- planner/generator/evaluator separation improves long-running application quality;
- complex prompts benefit from clear sections and explicit output contracts;
- system-agnostic VTT architecture benefits from a generic core plus installable game systems;
- map/token, character-sheet, journal/knowledge, item, and encounter concepts are established VTT primitives.

Primary sources consulted:

- Anthropic Claude Code documentation: memory, subagents, prompting best practices.
- Anthropic Engineering: Claude Code best practices; effective harnesses for long-running agents; harness design for long-running application development; effective context engineering.
- Foundry Virtual Tabletop official documentation: systems, actors, scenes, items, journals.
- Roll20 official site and help centre: maps, tokens, character sheets, drawing, lighting, compendium.
- D&D Beyond official Maps pages.
- How to be a Hero official rulebook and character-sheet pages.

Verify licences again before distributing external rules content or artwork.
